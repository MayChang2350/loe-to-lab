# Reflection page photos

Drop up to 6 photos in this folder, named exactly:

```
reflection-1.jpg
reflection-2.jpg
reflection-3.jpg
reflection-4.jpg
reflection-5.jpg
reflection-6.jpg
```

- `.jpg` extension specifically (not `.jpeg`/`.png`) — the gallery only looks for that filename pattern.
- You don't need all 6. Any slot without a matching file just shows the empty dashed placeholder instead of a broken image.
- No code changes needed — the Reflection page (hamburger menu → Reflection) picks these up automatically once they're in this folder.
